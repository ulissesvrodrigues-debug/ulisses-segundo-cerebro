# Ulisses — Segundo Cérebro

Base de conhecimento enxuta para a Atena e agentes especialistas.

Objetivo: guardar decisões, contexto, procedimentos, links importantes e próximos passos dos projetos do Ulisses, sem virar depósito de conversa solta.

## Estrutura

- `00-inbox/` — captura rápida ainda não organizada.
- `01-projetos/` — projetos ativos: Pratsy, VzBot 235, BASIC.
- `02-areas/` — áreas contínuas: estudos de IA, pessoal, financeiro.
- `03-recursos/` — fornecedores, cursos, links e referências.
- `04-decisoes/` — decisões tomadas e decisões em aberto.
- `99-arquivo/` — material antigo ou inativo.

## Regra de ouro

Só registrar o que poderá ser útil no futuro: decisões, processos, links, listas, padrões, aprendizados e pendências.
